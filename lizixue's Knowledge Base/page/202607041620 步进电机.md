### 步进电机选型流程

- 1.确认电机类型（综合使用需求和经济性来判断） 。
- 2.确然电机品牌。（根据预算选品牌，看采购选品牌）。
- 3.步进电机来讲，需要判断步距角（单位移动量：电机旋转一圈，执行机构运行的距离）;皮带机构（同步带、平皮带...) 电机旋转一圈皮带前进距离为皮带轮的周长。

分辨率的计算：  
- 步距角1.8°，走一圈要200步。皮带轮周长125mm（$皮带轮的有效直径*3.14=周长$）
- 推算得到：电机前进一个步距角，那么$皮带上的机构前进距离=\frac{125mm}{200}=0.625mm$
- 假如2222该机构的定位间隙为0.2mm，意味着不论前进还是后退都找不到位置，因为分辨率过低，往前或者往后都是0.625mm，精度不够。

| 步距角(°) | 皮带轮周长(mm) | 前进距离(mm)     |
| ------ | --------- | ------------ |
| 1.8    | 100       | `=a2*b2/360` |

- 解决方案：

1.加减速机（i=5），意味着电机转一圈，皮带轮转1/5圈（72°），电机前进一步，皮带前进$\frac{0.625mm}{5}=0.125mm$。加减速机需要考虑减速机的间隙（有可能导致精度进一步下降）。
2.换电机型号，亮相的不行换三相，三相不行换五相，再不行让电气工程师做细分。

- 4.判断转速需求：步进电机常用转速在200-600rpm之间。

$$N=\frac{V}{A}rps (V是负载速度，A是电机旋转一周负载移动量）$$

| 负载速度（mm/s） | 电机旋转一周负载移动量(mm) | 转速(rps)  |
| ---------- | --------------- | -------- |
|            |                 | `=a2/b2` |

- 5.计算负载然后判断转矩。

$$加速过程中受力：F=（ma+\mu mg）N$$$$a=\frac{V}{t}（步进电机加速时间一般为1-2s，伺服电机加速时间为0.5-1s）$$
$$
皮带轮最大输出扭矩:T=(FR)N.m
$$
$$T_2=T*2(2为安全系数）$$

| 负载重量 | 负载速度 | 皮带轮半径 | 输出扭矩                        |
| ---- | ---- | ----- | --------------------------- |
| 25   | 0.5  | 0.05  | `=(a2*(b2/1)+0.1*a2*10)*c2` |

- 6.选择电机具体型号。（需要与电气沟通）
